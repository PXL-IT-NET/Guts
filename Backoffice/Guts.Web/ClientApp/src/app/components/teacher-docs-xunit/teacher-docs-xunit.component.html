• [MonitoredFact] replaces [Fact] for single-case tests.

    The method name is used as test name in GUTS, and camel case is split into words. For example, ShouldBeAtLeast300PixelsWide becomes Should be at least 300 pixels wide.
  • [MonitoredFact("Custom test name")] sets a custom report name. Most of the time, the default method-based name is sufficient.
  • [MonitoredTheory] replaces [Theory] for parameterized runs.
  • Combine [MonitoredTheory] with [InlineData] for data-driven scenarios.
